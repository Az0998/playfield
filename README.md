# PLAYFIELD

轻量网页街机合集：回声网格、轨道切片、色相对决、脉冲节拍。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

静态产物在 `dist/`，可部署到 GitHub Pages / Cloudflare Pages / 任意静态托管。

## 游戏

| 游戏 | 玩法 |
|------|------|
| 回声网格 | 记忆亮格顺序并复现 |
| 轨道切片 | 球体进入橙色区时点击 |
| 色相对决 | 点中目标色（忽略文字干扰） |
| 脉冲节拍 | 圆环收缩到目标时点击/空格 |
